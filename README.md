# AirPods Case — ใช้ฝาเคส AirPods เป็นตัวควบคุมหน้าเว็บ

เปิดฝาเคส AirPods ใกล้ Mac แล้วหน้าเว็บจะเล่นเอฟเฟกต์ดอกไม้/ผีเสื้อ และแสดงแบตของหูฟังซ้าย ขวา และเคส
ถ้าปิดฝา หน้าเว็บจะกลับไปเป็นเคสปิด

```
เคส AirPods ──Bluetooth──▶ ble-apple-scan (Mac) ──WebSocket──▶ game.html (เบราว์เซอร์)
```

- `ble-apple-scan` เป็นโปรแกรม Swift ที่ฟังสัญญาณ Bluetooth ของเคส แล้วอ่านสถานะฝากับแบตออกมา
  จากนั้นเปิดเว็บที่ `http://localhost:8787` และส่ง event เปิด/ปิดฝาให้หน้าเว็บ
- `game.html` คือหน้าเว็บที่โปรแกรมเสิร์ฟให้เบราว์เซอร์

## สิ่งที่ต้องมี

- Mac ที่มี Bluetooth
  - Apple Silicon (M1 ขึ้นไป): macOS 11 Big Sur ขึ้นไป
  - Intel: macOS 13 Ventura ขึ้นไป
- AirPods หรือ Beats ที่เคสชาร์จเปิดฝาได้ ได้แก่ AirPods 1–4, AirPods Pro ทุกรุ่น, Powerbeats Pro, Beats Fit Pro, Beats Studio Buds
  (AirPods Max และหูฟังครอบหูใช้ไม่ได้ เพราะไม่มีเคสแบบฝาเปิด)
- อินเทอร์เน็ต ใช้แค่โหลดฟอนต์ Kanit ถ้าออฟไลน์ หน้าเว็บจะใช้ฟอนต์ของเครื่องแทน

## ใช้งานบน Mac เครื่องนี้

ดับเบิลคลิก `jackpot.command`

1. Terminal.app จะเปิดขึ้นมา และเบราว์เซอร์จะเปิด `http://localhost:8787` ให้เอง
2. วางเคส AirPods ไว้ชิด Mac แล้วเปิดฝา
3. ถ้าจะหยุด ให้กด Control+C ใน Terminal หรือปิดหน้าต่าง Terminal ไปเลย

ควรรันผ่าน Terminal.app เสมอ ถ้ารันใน terminal ของ editor หรือแอปอื่น โปรแกรมจะตายเมื่อแอปนั้นปิดหรือรีสตาร์ต

## ติดตั้งบน Mac เครื่องอื่น

ชุดสำหรับแจกอยู่ที่ `dist/AirPods-Case.zip` ข้างในเป็นโปรแกรม universal ที่รันได้ทั้ง Apple Silicon และ Intel
เครื่องปลายทางไม่ต้องติดตั้ง Xcode หรือเครื่องมืออื่นเพิ่ม

### 1. ส่งไฟล์

ส่ง `dist/AirPods-Case.zip` ไปที่เครื่องปลายทาง ใช้ AirDrop, USB หรือแชตก็ได้
แล้วดับเบิลคลิก zip เพื่อแตกไฟล์ จะได้โฟลเดอร์ `AirPods-Case` ย้ายไปไว้ที่ไหนก็ได้ เช่น Documents

ในโฟลเดอร์มีไฟล์ต่อไปนี้:

| ไฟล์ | หน้าที่ |
|---|---|
| `เปิดใช้งาน.command` | ดับเบิลคลิกเพื่อเริ่มโปรแกรม |
| `ble-apple-scan` | ตัวโปรแกรม |
| `game.html` | หน้าเว็บ |
| `วิธีติดตั้ง.txt` | คู่มือฉบับเต็มสำหรับผู้ใช้ |
| `source/` | ซอร์สโค้ดและ `build.sh` ไว้คอมไพล์ใหม่ |

### 2. ปลดล็อกไฟล์ (ทำครั้งเดียว)

macOS จะบล็อกไฟล์ที่ดาวน์โหลดมาและไม่ได้ลงทะเบียนกับ Apple เลือกปลดล็อกวิธีใดวิธีหนึ่ง:

**วิธี ก (แนะนำ):** เปิด Terminal พิมพ์ `xattr -dr com.apple.quarantine` เว้นวรรคหนึ่งครั้ง
ลากโฟลเดอร์ `AirPods-Case` มาวางในหน้าต่าง Terminal แล้วกด Return

**วิธี ข:** ดับเบิลคลิก `เปิดใช้งาน.command` ถ้ามีข้อความว่าเปิดไม่ได้เพราะไม่รู้จักผู้พัฒนา:
- macOS 15 ขึ้นไป: กด Done แล้วไปที่ System Settings > Privacy & Security เลื่อนลงล่าง กด **Open Anyway** แล้วยืนยันอีกครั้ง
- macOS 11–14: คลิกขวาที่ไฟล์ เลือก **Open** แล้วกด Open อีกครั้ง

### 3. ให้สิทธิ์ Bluetooth

ตอนรันครั้งแรก macOS จะถามว่าให้ Terminal ใช้ Bluetooth ได้ไหม ให้กด **Allow**
ถ้าเผลอกดไม่อนุญาตไปแล้ว ให้ไปที่ System Settings > Privacy & Security > Bluetooth เปิดสวิตช์ของ Terminal
แล้วปิด Terminal และเปิดใหม่

### 4. ใช้งาน

1. ดับเบิลคลิก `เปิดใช้งาน.command` เบราว์เซอร์จะเปิด `http://localhost:8787` ให้เอง
2. วางเคสไว้ใกล้ Mac แล้วเปิดฝา ถ้าป้ายบนหน้าเว็บขึ้นว่า "เคสยังหลับ" ให้เปิดแล้วปิดฝาหนึ่งครั้ง
3. ถ้าจะหยุด ให้กด Control+C หรือปิดหน้าต่าง Terminal

## ปรับตั้งค่า

เปิด `เปิดใช้งาน.command` ด้วย TextEdit แก้บรรทัดที่ต้องการแล้วบันทึก

| บรรทัด | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `RSSI=${RSSI:--42}` | -42 | ระยะจับสัญญาณ ถ้าเปิดฝาแล้วหน้าเว็บไม่ตอบสนอง ให้เปลี่ยนเป็น `-55` เพื่อให้วางเคสห่างจาก Mac ได้มากขึ้น |
| `PORT=${PORT:-8787}` | 8787 | พอร์ตของหน้าเว็บ ถ้ามีโปรแกรมอื่นใช้พอร์ตนี้อยู่แล้ว ให้เปลี่ยนเป็นเลขอื่น |
| `PHONE=${PHONE:-0}` | 0 | ตั้งเป็น `1` เพื่อให้มือถือที่ต่อ Wi-Fi เดียวกันเปิดดูได้ (ดูหัวข้อถัดไป) |

### ดูจากมือถือ

พอตั้ง `PHONE` เป็น `1` แล้ว Terminal จะแสดงบรรทัดแบบนี้:

```
phone on the same Wi-Fi: http://192.168.1.20:8787/?k=...
```

ให้เปิดลิงก์นี้ทั้งบรรทัดในมือถือ รวมรหัสหลัง `?k=` ด้วย มือถือต้องต่อ Wi-Fi เดียวกับ Mac
ลิงก์จะเปลี่ยนทุกครั้งที่เปิดโปรแกรม และ Mac ต้องเปิดโปรแกรมค้างไว้ตลอด เพราะ Mac เป็นเครื่องที่อ่าน Bluetooth
ถ้า macOS ถามเรื่องรับการเชื่อมต่อจากเครือข่าย ให้กด Allow

## ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| เปิดฝาแล้วหน้าเว็บไม่ตอบสนอง | วางเคสให้ใกล้ Mac กว่าเดิม หรือเปลี่ยน `RSSI` เป็น `-55` |
| ป้ายขึ้นว่า "สแกนเนอร์หลุด" | หน้าต่าง Terminal ถูกปิดไป ให้ดับเบิลคลิก `เปิดใช้งาน.command` ใหม่ |
| Terminal ขึ้นว่า `bluetooth is off` / `permission denied` | เปิด Bluetooth แล้วให้สิทธิ์ตามขั้นตอนที่ 3 |
| Terminal ขึ้นว่า `could not listen on port 8787` | เปลี่ยน `PORT` เป็นเลขอื่น เช่น 8790 |
| มีเคสหลายใบอยู่ใกล้กัน | หน้าเว็บตามได้ทีละเคส เคสที่ขยับฝาล่าสุดจะได้หน้าเว็บไป ถ้ามีเคสอื่นเปิดฝาค้างอยู่ ต้องปิดฝาเคสนั้นก่อน หรือรอให้มันออกนอกระยะเกิน 8 วินาที |
| อยากดูค่าที่โปรแกรมอ่านได้ | เปิดไฟล์ `scan.log` ในโฟลเดอร์ |
| `ble-apple-scan` รันไม่ได้บนเครื่องนั้น | คอมไพล์ใหม่: รัน `xcode-select --install` แล้วรัน `zsh source/build.sh` |

## ความปลอดภัย

- โปรแกรมใช้แค่ Bluetooth กับพอร์ต 8787 และไม่ส่งข้อมูลออกนอกเครื่อง สิ่งเดียวที่หน้าเว็บโหลดจากภายนอกคือ Google Fonts
- ค่าเริ่มต้นเปิดหน้าเว็บได้เฉพาะบน Mac เครื่องนั้น และเว็บไซต์อื่นที่เปิดอยู่จะอ่านข้อมูลแบตไม่ได้
- ถ้าเปิดโหมดมือถือ ต้องมีรหัสในลิงก์ถึงจะเปิดได้ อย่าแชร์ลิงก์นี้ให้คนอื่น
- สัญญาณ Bluetooth ของ AirPods ไม่มีการยืนยันตัวตน ข้อนี้แก้ไม่ได้ คนที่อยู่ใกล้มากพร้อมอุปกรณ์ปลอมสัญญาณจะทำให้หน้าเว็บแสดงค่าปลอมได้
- โปรแกรมไม่ได้ลงทะเบียนกับ Apple และ `เปิดใช้งาน.command` จะปลดล็อกทุกไฟล์ในโฟลเดอร์ ให้รับ zip จากเจ้าของโดยตรงเท่านั้น

## สำหรับนักพัฒนา

### ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `ble-apple-scan.swift` | ซอร์สของตัวสแกน Bluetooth + เว็บเซิร์ฟเวอร์ + WebSocket |
| `game.html` | หน้าเว็บที่ build แล้ว (มีรูปฝังเป็น data URI) |
| `ui-src/` | template ของหน้าเว็บ, รูปเคส และสคริปต์ build |
| `jackpot.command` | รันใช้งานจริง (`--serve 8787 --open --rssi -42`) |
| `scan.command` | ทดสอบตัวจับฝาอย่างเดียว พิมพ์ `LID OPENED/CLOSED` ออกมา |
| `debug.command` | พิมพ์ทุกแพ็กเก็ตลง `debug.log` |
| `tests/` | เทสต์ follow (การเลือกเคส) และ security (WebSocket) |
| `dist/AirPods-Case/` | ชุดสำหรับแจก |

### Build

```bash
# ตัวโปรแกรม (ต้อง ctrl-c ตัวเก่าแล้วรันใหม่ทุกครั้งหลัง build)
swiftc -O ble-apple-scan.swift -o ble-apple-scan \
  -Xlinker -sectcreate -Xlinker __TEXT -Xlinker __info_plist -Xlinker Info.plist \
  && codesign -s - -f ble-apple-scan

# หน้าเว็บ: สร้าง game.html จาก ui-src/game.template.html
python3 -I ui-src/build.py

# เทสต์
zsh tests/run-follow-test.sh
zsh tests/run-security-test.sh
```

ต้องฝัง `Info.plist` ลงในไบนารี เพราะ macOS จะถามสิทธิ์ Bluetooth ได้ก็ต่อเมื่อมีคำอธิบายการใช้งานอยู่ในนั้น
ถ้าไม่มี โปรแกรมจะจบด้วย exit 134
ตัวที่แจกใน `dist/` เป็น universal binary: arm64 ขั้นต่ำ macOS 11 และ x86_64 ขั้นต่ำ macOS 13 ตามขั้นตอนใน `dist/AirPods-Case/source/build.sh`

### ตัวเลือกของ `ble-apple-scan`

| ตัวเลือก | ความหมาย |
|---|---|
| `--serve <port>` | เปิดเว็บเซิร์ฟเวอร์และ WebSocket (`/ws`) |
| `--open` | เปิดเบราว์เซอร์ให้เอง |
| `--rssi <dBm>` | รับเฉพาะสัญญาณที่แรงกว่าค่านี้ (ค่าเริ่มต้น -70) |
| `--lan` | ให้เครื่องอื่นใน Wi-Fi เดียวกันเข้าได้ แต่ต้องใช้รหัส `?k=` ที่สร้างใหม่ทุกครั้งที่รัน |
| `--verbose`, `--debug`, `--trace`, `--raw`, `--full`, `--all` | ตัวเลือกสำหรับดูแพ็กเก็ตตอน debug |
